# 当前工作流界面汉化设计

## 目标与范围

将当前 ASR 项目实际使用的登录、标注、管理后台和管理员审核界面完整汉化。
保持页面结构、交互、权限、任务分配、标注数据和导出格式不变。

本次不汉化 Potato 中未使用的数据集、模型评测、Solo Mode 等模块。

## 实现方式

优先使用项目 `config.yaml` 已有的 `ui_language` 配置。配置无法覆盖的文字，
只修改当前流程直接使用的模板和前端脚本：

- 登录页：账号、密码、登录提示及错误信息；
- 标注页：导航、播放、波形、片段操作、状态和帮助文字；
- 管理后台：标注员列表、任务配额、进度、操作按钮及提示；
- 审核页：队列、筛选、标注结果、审核决定、置信度、备注、跳过和提交提示。

账号名、录音 ID、程序字段名、URL、文件名以及导出 JSON 键保持原样，避免破坏
数据兼容性。中文术语统一为“管理员”“标注员”“审核”“待审核”“审核中”
“已完成”“跳过”“置信度”。

## 边界与错误处理

- 不改变任何接口路径和请求字段；
- 不翻译后端日志、源代码标识符和数据键；
- 浏览器提示和接口错误在当前页面展示时使用中文；
- 若文字来自共用模板，只对当前页面传入中文或增加局部映射，避免影响其他示例。

## 验证

- 自动检查四类页面的关键中文文字；
- 检查主要英文按钮和状态词不再出现在当前页面；
- 回归验证管理员登录、任务配额、标注员标注和管理员审核接口；
- 在 8012 端口逐页检查登录、标注、管理和审核页面。
