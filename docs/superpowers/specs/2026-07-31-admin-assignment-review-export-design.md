# 管理员分配、全量审核与导出设计

## 目标

在当前 ASR 音频标注项目中形成以下闭环：

1. 管理员登录管理后台并设置每名标注员的任务数量；
2. 系统自动为标注员分配录音；
3. 标注员完成音频片段、说话人和转写文本标注；
4. 管理员审核所有满足覆盖条件的录音；
5. 管理员导出最终结果。

本次优先复用仓库已有的认证、RBAC、管理后台、任务分配、仲裁和导出能力，不新增统一管理页面。

## 账号与权限

| 账号 | 初始密码 | 角色 | 权限 |
|---|---|---|---|
| `admin` | `123` | `admin` | 管理后台、任务数量设置、全量审核、导出 |
| `user2` | `123` | `annotator` | 音频标注 |
| `tester_a` | `123` | `annotator` | 音频标注 |
| `tester_b` | `123` | `annotator` | 音频标注 |

所有账号均启用密码登录，关闭任意用户注册。密码通过项目现有认证机制生成安全哈希后保存，不在用户文件中保存明文。`123` 仅用于本机测试，正式使用前必须修改。

## 任务分配

- 分配策略使用 `least_annotated`，优先选择当前标注次数较少的录音。
- 每条录音的目标覆盖数为 2，满足多人标注和后续审核条件。
- 管理员在 `/admin` 的标注员列表中设置每名用户的最大任务数量。
- 已完成数量不能被管理员调低；调整后的上限立即作用于后续分配。
- 管理员账号不参与普通录音分配。

## 标注流程

标注员使用各自账号登录普通页面。系统根据账号任务上限和当前录音覆盖数分配任务。标注员完成以下内容后提交：

- 片段开始和结束时间；
- 说话人标签；
- 片段转写文本。

结果继续按用户保存在项目的 `annotation_output` 目录中。

## 全量审核

- 启用仓库现有的 adjudication 工作流；
- `admin` 同时拥有审核权限；
- `min_annotations` 设置为 2；
- `show_all_items` 设置为 `true`；
- 每条达到两份标注的录音均进入 `/adjudicate`，不论两份结果是否一致；
- 未达到两份标注的录音不进入审核队列；
- 管理员提交审核决定，形成最终版本及来源记录。

音频标注包含时间区间、说话人和自由文本。验收时必须验证现有仲裁页面能完整展示并保存这三类字段；若通用仲裁组件不能正确处理音频片段，实施范围只补齐该兼容缺口，不扩展其他标注类型。

## 导出

管理员审核后使用现有导出能力生成最终 JSON。导出结果应：

- 对已审核项目采用管理员最终决定；
- 保留录音 ID；
- 保留片段起止时间、说话人和转写文本；
- 不将用户内部状态文件作为交付结果；
- 对尚未达到两份标注或尚未审核的项目给出明确提示，不静默混入最终数据。

## 页面入口

| 用途 | 地址 |
|---|---|
| 账号登录与标注 | `/`、`/annotate` |
| 管理与任务数量设置 | `/admin` |
| 全量审核 | `/adjudicate` |
| 数据导出 | 管理后台现有导出入口或受 RBAC 保护的导出接口 |

管理后台和审核页面保留为两个独立入口，不在本次范围内合并为统一操作台。

## 错误与边界处理

- 非管理员访问管理或审核接口时返回无权限，不泄露数据；
- 未知账号和密码错误时拒绝登录；
- 管理员不能把任务上限调低到用户已完成数量以下；
- 录音未达到两份标注时不得进入全量审核；
- 导出前应显示未完成、未审核数量；
- 服务重启后应恢复用户进度、分配和审核结果。

## 验收标准

1. 四个预置账号均可使用初始密码登录；
2. 普通标注员不能访问 `/admin` 和 `/adjudicate`；
3. `admin` 可访问管理后台、修改每名标注员的任务上限；
4. 系统按 `least_annotated` 分配，单条录音最多分给 2 名标注员；
5. 两名标注员完成同一录音后，该录音出现在管理员审核队列；
6. 结果一致的录音也出现在审核队列；
7. 管理员可以查看并确认音频时间片段、说话人和文本；
8. 最终 JSON 可导出且包含审核后的音频片段数据；
9. 重启服务后账号、进度和审核结果仍可恢复；
10. ASR 标注页面的现有左右布局和交互不发生回归。

## 测试范围

- 配置校验测试：密码认证、RBAC、覆盖数、分配策略和 adjudication 配置；
- 权限测试：管理员与标注员路由访问控制；
- 分配测试：用户上限、两人覆盖和 `least_annotated`；
- 审核测试：一致项与分歧项均进入队列，音频片段可保存；
- 导出测试：仅输出符合条件的最终数据；
- 浏览器冒烟测试：登录、管理、标注、审核和导出主路径。
