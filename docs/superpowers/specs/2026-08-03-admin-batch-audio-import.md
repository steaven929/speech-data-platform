# 管理员批量导入音频

管理员在管理后台同时上传原始 `.xls` 和多条 `.wav`。系统读取原表的“录音地址”和“阿里转译”列，以录音地址中的文件名匹配上传音频；转写按空行拆分为片段，并按音频总时长及片段字符数生成连续时间段，角色从客服开始交替。

导入分为预览和确认两步，并以上传的 WAV 作为本次导入范围。Excel 中未选择对应 WAV 的行直接忽略；预览列出可导入、已忽略、找不到 Excel 记录、重复任务和解析错误。确认时仅在所有已选择音频通过校验后，将音频写入配置的 `media_directory`、任务追加到首个 JSON `data_files`，并加入运行中的任务管理器。已有音频、任务、分配和标注不得覆盖。首版只兼容当前原始 `.xls` 格式与 WAV 音频。

所有接口仅管理员可访问。上传文件名必须净化，限制文件扩展名、数量和总体积；失败不得留下部分文件或半写入的任务清单。导入文件继续由现有 `.gitignore` 排除。
