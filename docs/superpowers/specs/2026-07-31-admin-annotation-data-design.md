# 管理后台标注数据页面设计

## 目标

在现有 `/admin` 管理后台增加“标注数据”页面，让管理员直接查看已经成功保存的录音标注，并下载 JSON 或 SQLite 格式的标注结果。

## 页面

- 新增“标注数据”导航项，不改变现有标注员、任务分配和统计页面。
- 列表按“录音”展示，包含录音编号、标注员、片段数量和保存状态。
- 支持按标注员和录音编号筛选。
- 展开一条录音后，展示每个片段的开始时间、结束时间、说话人、转写文本和方言标记。
- 空数据、读取失败和下载失败均显示中文提示。

## 数据读取

- 页面只读取后端已经持久化的标注，不把原始数据中的预置转写误认为用户已提交标注。
- 后端统一解析 `transcript_segments:_data` 和 `transcript_segments:::_data` 两种历史键格式。
- 管理 API 返回稳定的普通 JSON 结构，不向前端暴露 Python 对象或内部状态文件结构。
- 所有新增页面和接口均复用现有管理员身份与 API 密钥校验。

## 导出

### JSON

下载一个 UTF-8 JSON 文件。顶层包含导出时间、录音数量、标注数量和 `annotations` 数组；每条记录包含录音编号、标注员及完整片段。

### SQLite

下载独立的标注结果数据库，不直接下载现有 `project.sqlite`。数据库包含：

- `annotations`：一行对应一个标注员对一条录音的提交；
- `segments`：一行对应一个标注片段，通过 `annotation_id` 关联；
- 索引：录音编号、标注员、片段所属标注。

SQLite 导出使用临时文件生成并在响应结束后清理。

## 权限与错误处理

- 非管理员访问页面或接口时拒绝访问。
- 没有已保存标注时，页面显示空状态；导出仍产生结构正确的空文件。
- 格式错误的单条历史标注不会导致整个页面或导出失败；该条记录显示解析错误并从片段统计中排除。

## 测试

- 单元测试覆盖标注解析、排序和异常数据。
- Flask 接口测试覆盖管理员权限、列表数据、JSON 下载和 SQLite 表结构。
- 页面测试覆盖中文导航、筛选控件、详情字段及两个下载按钮。
- 回归测试确认现有管理后台与审核页面仍可访问。

## 非目标

- 本功能不修复标注员前端“预置片段未写入提交字段”的问题。
- 本功能不把录音二进制文件写入 JSON 或 SQLite。
- 本功能不修改已有 `project.sqlite` 的表结构。
